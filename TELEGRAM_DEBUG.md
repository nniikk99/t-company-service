# 🔍 Диагностика Telegram Mini App

## Проблема: "Страница не найдена" в Telegram Mini App

### Шаги для диагностики:

#### 1. Проверь URL в BotFather
Выполни команды в боте @BotFather:

```
/setmenubutton
@Assistant_t_co_bot
T-Company Service
https://nniikk99.github.io/t-company-service/
```

**Важно:** URL должен быть точно таким же, без слеша в конце!

#### 2. Протестируй простую страницу
Сначала протестируй простую HTML страницу:
```
https://nniikk99.github.io/t-company-service/test.html
```

Если эта страница работает в Telegram Mini App, то проблема в Flutter приложении.
Если не работает - проблема в настройках GitHub Pages или BotFather.

#### 3. Проверь основное приложение
```
https://nniikk99.github.io/t-company-service/
```

#### 4. Проверь в обычном браузере
Открой оба URL в обычном браузере (Chrome/Firefox) и убедись, что они работают.

### Возможные причины:

1. **Неправильный URL в BotFather** - самая частая причина
2. **GitHub Pages блокирует iframe** - проблемы с заголовками безопасности
3. **Проблемы с Flutter Web** - ошибки в JavaScript
4. **Кэширование** - старые версии в кэше Telegram

### Решения:

1. **Обнови URL в BotFather** с точным адресом
2. **Подожди 5-10 минут** после обновления URL
3. **Очисти кэш** Telegram (перезапусти приложение)
4. **Проверь GitHub Actions** - убедись, что деплой прошел успешно

### Следующие шаги:

1. Протестируй `test.html` в Telegram Mini App
2. Если работает - проблема в основном приложении
3. Если не работает - проблема в настройках GitHub Pages
4. Сообщи результат для дальнейшей диагностики
