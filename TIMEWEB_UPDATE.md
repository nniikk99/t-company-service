- **Статус:** Работает (Nginx успешно запущен)

## 📋 Что нужно сделать:

### **Вариант 1: Автоматическое обновление (РЕКОМЕНДУЕТСЯ)**

1. **Открой Timeweb Cloud:**
   - Перейди: https://timeweb.cloud/
   - Войди в аккаунт

2. **Найди приложение:**
   - Боковое меню → **Apps**
   - Выбери **"Service AI"**

3. **Пересобери приложение:**
   - Нажми на **три точки** (⋮) справа от названия
   - Выбери **"Пересобрать"** или **"Rebuild"**
   - Подтверди действие

4. **Дождись завершения:**
   - Процесс займет **2-3 минуты**
   - Статус изменится на "В сети" (зеленый)

5. **Проверь результат:**
   - Открой https://nniikk99-t-company-service-2706.twc1.net
   - Попробуй войти: `+79817467395` / `admin8602`
   - Проверь кнопки (они должны работать!)

---

### **Вариант 2: Ручное пересоздание (если Вариант 1 не сработал)**

1. **Удали старое приложение:**
   - Apps → Service AI → три точки → **"Удалить"**
   - Подтверди удаление

2. **Создай новое приложение:**
   - Нажми **"Создать приложение"**
   - Выбери **"Docker"**
   - Настройки:
     - **Название:** Service AI
     - **Репозиторий:** https://github.com/nniikk99/t-company-service.git
     - **Ветка:** main
     - **Dockerfile:** Выбери "Да" (использовать Dockerfile из репозитория)
     - **Путь к Dockerfile:** `./Dockerfile` (корень репозитория)
   - Нажми **"Создать"**

3. **Дождись развертывания:**
   - Процесс займет **5-7 минут**
   - Статус изменится на "В сети"

4. **Проверь новый URL:**
   - Timeweb автоматически создаст новый URL
   - Скопируй его и обнови в BotFather

---

### **Вариант 3: Проверка через логи (для диагностики)**

1. **Открой логи приложения:**
   - Apps → Service AI → вкладка **"Логи приложения"**

2. **Проверь строки:**
   ```
   172.17.0.1 - - [timestamp] "GET / HTTP/1.1" 200 37601
   ```
   - **200** = успешно
   - **37601** = размер файла (должен быть больше после обновления, ~45-50 KB)

3. **Если размер не изменился:**
   - Используй **Вариант 2** (пересоздание)

## 🔍 Как проверить, что всё работает:

После обновления проверь:

1. **Авторизация:**
   - Войди как админ: `+79817467395` / `admin8602`
   - Должно открыться главное меню

2. **Кнопки:**
   - Нажми кнопку "+" в разделе "Заявки"
   - Должно появиться окно "Опишите проблему"

3. **Загрузка данных:**
   - Перейди в раздел "Заявки"
   - Должно быть: "Загрузка заявок..." → "Заявок пока нет. Создайте первую заявку!"

4. **Console логи (F12):**
   - Открой консоль браузера (F12 → Console)
   - Должны быть логи:
     ```
     Script started
     DOM loaded, adding event listeners...
     Page loaded, checking auth status...
     ```

## ⚠️ Если что-то не работает:

### Проблема: Кнопки не реагируют
**Решение:** Очисти кеш браузера (Ctrl + Shift + Delete) и обнови страницу (Ctrl + F5)

### Проблема: Ошибка "Supabase is not defined"
**Решение:** Приложение не обновилось. Используй **Вариант 2** (пересоздание)

### Проблема: Страница не открывается
**Решение:** Проверь статус приложения в Timeweb Cloud. Должно быть "В сети" (зеленый)

### Проблема: "Страница не найдена" в Telegram
**Решение:** Обнови URL в BotFather командой `/setmenubutton`
