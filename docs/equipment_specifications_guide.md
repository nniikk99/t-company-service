# Руководство по техническим характеристикам оборудования

## 📋 Обзор

Система технических характеристик позволяет отображать подробную техническую информацию о каждой модели оборудования в приложении.

## 🎯 Добавленные характеристики

### Основные параметры (с иконками):
- **Мощность** (кВт) - ⚡ оранжевая иконка
- **Напряжение** (В) - 🔌 синяя иконка  
- **Вес** (кг) - 🏋️ серая иконка
- **Габариты** (мм) - 📐 фиолетовая иконка
- **Рабочая температура** (°C) - 🌡️ красная иконка

### Дополнительные параметры:
- Место для оператора
- Производительность (теоретическая), кв.м/ч
- Ширина уборки
- Ширина скребка
- Количество щеток
- Диаметр щетки
- Максимальное давление щеток / пада на пол
- Скорость вращения щеток, об/мин
- Тип уборочного узла
- Объем бака чистой воды
- Объем бака грязной воды
- Максимальный угол подъема
- Тип питания

## 📁 Структура файлов

### 1. `lib/data/equipment_specifications.dart`
База данных технических характеристик для всех моделей оборудования.

**Структура данных:**
```dart
'gadlee_gt110': {
  'power': {'value': '37', 'unit': 'кВт', 'label': 'Мощность'},
  'voltage': {'value': '380', 'unit': 'В', 'label': 'Напряжение'},
  // ... остальные характеристики
}
```

### 2. `lib/widgets/equipment_specifications_widget.dart`
Виджет для красивого отображения технических характеристик.

**Использование:**
```dart
EquipmentSpecificationsWidget(
  manufacturer: 'Gadlee',
  model: 'GT110',
)
```

## 🚀 Как добавить характеристики для новой модели

1. Откройте файл `lib/data/equipment_specifications.dart`
2. Добавьте новую запись в `_specifications`:

```dart
'производитель_модель': {
  'power': {'value': '37', 'unit': 'кВт', 'label': 'Мощность'},
  'voltage': {'value': '380', 'unit': 'В', 'label': 'Напряжение'},
  'weight': {'value': '1450', 'unit': 'кг', 'label': 'Вес'},
  // ... добавьте все нужные характеристики
},
```

3. Характеристики автоматически отобразятся в деталях оборудования!

- ✅ Разделяет секции линиями
- ✅ Выравнивает значения по правому краю
- ✅ Показывает единицы измерения
- ✅ Адаптируется под разные размеры экрана

## 📊 Где отображаются характеристики

Технические характеристики отображаются:
1. В деталях оборудования (нажатие на карточку)
2. В разделе "Технические характеристики"
3. Между секциями "Размещение" и "Кнопками действий"

## 💡 Примечания

- Если для модели нет характеристик, показывается сообщение "Технические характеристики пока не добавлены"
- Ключ в базе данных формируется как: `производитель_модель` (lowercase)
- Все единицы измерения указываются в метрической системе
- Характеристики структурированы для удобного парсинга и отображения
